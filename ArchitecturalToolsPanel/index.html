Rectangle

Dimensions

Select the dimensioned group, choose a dimension above, change the offset, and click Apply offset. Larger offsets move it farther out; smaller offsets bring it closer. You can also select one dimension inside the group to adjust only that dimension.

Width/height use the selected object's geometric bounds (excluding stroke). Straight-line mode uses the endpoints of a selected two-anchor path. Artwork and new dimensions are grouped: move them together with the Selection tool (V). Add another dimension with the group selected. Resizing does not update labels; ungroup and remove old dimensions before measuring again.
