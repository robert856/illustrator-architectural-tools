# Illustrator Architectural Tools

Adobe Illustrator CEP architectural drawing and dimensioning panel.

Initial source is preserved under `ArchitecturalToolsPanel/`.

Development priorities:
1. Keep dimensions attached to shapes as they move or resize.
2. Create a clear break/white background behind dimension labels.
3. Preserve drawing scale and accurate measurements.

See `ArchitecturalToolsPanel/README.txt` for installation instructions and compatibility limitations.
